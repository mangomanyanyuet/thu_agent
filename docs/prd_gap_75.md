# PRD v1.0 缺口补齐：7.1 超时收尾 与 7.5 风险处理

> 背景：PRD 正文在 §5、§6.1、§6.2、§9.2、§9.3 中**多次引用 7.1 与 7.5**，
> 但第 7 节实际只有「非功能需求」，这两节内容缺失。
> §9.2 的 `risk_triggered` / `risk_level(none/watch/high)` / `resource_suggested`
> 三个字段失去了定义来源。
>
> 以下为补齐方案，按心理健康领域通行做法（C-SSRS 维度 + 危机干预常规）制定，
> **需产品/算法/临床顾问共同评审后方可定稿**。

---

## 7.1 超时与节奏控制

| 触发条件 | 处理 |
|---|---|
| 累计时长 ≥ 4:00 | 进入**收尾提醒**：Agent 在当前轮回应后追加一句自然过渡（"我们聊得挺多了，最后还有一件事想问你…"），不再开启新话题 |
| 累计时长 ≥ 5:30（硬上限） | 强制进入结束语，无论当前在第几轮 |
| 用户沉默 > 8s | Agent 主动轻声确认，一次话术：**"不着急，你可以慢慢说。"** |
| 同一轮内沉默累计 > 20s | 视为该轮放弃，Agent 换一个更轻的问题或直接进入收尾 |
| 已完成第 4 轮 | 进入结束语，不开启第 5 轮 |

**沉默计时不计入"对话时长"**（否则用户思考会被扣时间），但计入总墙钟时间。

## 7.5 风险信号识别与处理

### 7.5.1 分级定义

| 等级 | 判定口径 | 系统行为 |
|---|---|---|
| `none` | 无风险表达 | 常规流程，生成 Tier1/2 报告 |
| `watch` | 轻度消极：持续无望感、严重疲惫/倦怠、"活着没意思"但**无**自伤意念与计划 | 正常出报告，但在结束语中**温和提供**自助资源（非紧急），报告内 `resource_suggested=true` |
| `high` | 出现下列任一：<br>· 自伤/自杀意念<br>· 计划或准备行为<br>· 告别式/托付式表达<br>· 明确即刻意图 | **中断常规报告流程**，立即进入关怀+转介：展示危机热线、建议联系身边人/专业机构；`risk_triggered=true`，**不生成** Tier1/2 |

### 7.5.2 三通道并集升级（宁可误报，不可漏报）

与主线架构一致，风险检测独立于对话生成：

| 通道 | 依据 |
|---|---|
| 文本规则 | 风险词表（分级） |
| 模型语义 | LLM 判定隐晦表达、隐喻、反讽 |
| 多模态 | 语音：语调平板+语速过慢+长停顿；面部：持续悲伤/低活跃度；**模态不一致**（嘴上说好、表情低落）|

**取三通道最大值，只升不降。**

### 7.5.3 话术

**watch 级（结束语追加，温和、非惊吓）**
> "另外想跟你说一句：如果最近这种状态持续了一段时间，和信任的人聊聊、
> 或者了解一下专业的心理支持渠道，可能会有帮助。需要的话我可以把相关信息放在界面上。"

**high 级（立即切换，不追问细节、不评价）**
> "听到你说的这些，我很在意你现在的安全。
> 我不是专业的危机干预人员，但有一些人可以现在就帮到你——
> 如果你有伤害自己的想法，请立刻联系下面这些渠道，或让身边的人陪着你。
> 你现在不是一个人。"

随后界面固定展示（不折叠、不置于"查看详情"内）：

- 全国心理援助热线 **12356**
- 北京心理危机研究与干预中心 **010-82951332**
- 希望24热线 **400-161-9995**
- 紧急情况 **120 / 110**

### 7.5.4 硬性约束

1. `high` 级**不做常规情绪小结**（避免"你今天整体比较平静"这类结论在危机语境下造成冒犯）。
2. 热线号码走配置/数据库，可维护、可核验，不硬编码进 prompt。
3. 本产品不承诺 7×24 人工值守；若产品侧提供人工介入，需明确 SLA 与责任边界。
4. 建议引入精神卫生专业人员参与话术与分级规则评审（对应 PRD §10 开放问题）。

## 待确认问题（回抛产品）

1. `watch` 级是否需要在界面上**默认**露出资源入口，还是仅在结束语口头提及？
   （当前实现：结束语提及 + 报告内 `resource_suggested`，入口放 Tier1 末尾但标注非紧急）
2. 是否需要未成年人识别与差异化流程？（PRD §8 提到但§7 未定义具体机制）
3. 高风险事件是否需要落库并触发人工复核队列？
   （当前实现：落 `risk_flag` 表，与主线架构一致）
