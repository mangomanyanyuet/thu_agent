## 三、模拟数据清理

模拟数据**真实写库**，默认挂 `u_sim`，会话 summary 带 `[SIM]` 标记：

```bash
cd /mnt/kaiwu-user-mangoman/thu_agent/backend
/root/miniconda3/envs/qwen35/bin/python3 - <<'PY'
import sqlite3
from config import get_settings
path = get_settings().database_url.split("sqlite:///")[-1]
c = sqlite3.connect(path)
sids = [r[0] for r in c.execute("SELECT id FROM session WHERE summary LIKE '[SIM]%'")]
for s in sids:
    for t in ("message", "audit_trace", "risk_flag"):
        c.execute(f"DELETE FROM {t} WHERE session_id=?", (s,))
c.execute("DELETE FROM session WHERE summary LIKE '[SIM]%'")
for u in ("u_sim", "u_sim_fresh"):
    for t in ("risk_flag", "user_profile", "daily_record", "scale_score"):
        c.execute(f"DELETE FROM {t} WHERE user_id=?", (u,))
c.commit(); print("已清理会话:", len(sids), "| DB:", path)
PY
```

## 四、踩坑清单

| 现象 | 根因 | 修复 |
|---|---|---|
| `/api/sessions` 500 `No module named 'langgraph'` | `qwen35` 环境未装（requirements 已声明） | 用 qwen35 的 pip 装 |
| 装完仍 `No module named 'langgraph'` | 装到了 base（3.13），后端跑在 qwen35（3.12） | `/root/miniconda3/envs/qwen35/bin/python3 -m pip install ...` |
| `import graph` 失败 | 装到 langgraph 1.x，代码按 0.2.x 写 | 锁 `<0.3` / checkpoint-sqlite `<2.2` |
| `No module named 'patient_agent'` | 代码解压到 `thu_agent_1024/`，命令却在 `thu_agent/backend` | `cp -a thu_agent_1024/. thu_agent/` |
| UI 无「病人模拟」卡片 | `dist` 是旧的 / 接口 403 | 部署最新 `dist`；确认 `ENABLE_PATIENT_SIM=1` |
| tar `Can't add archive to itself` | 归档文件放在被打包目录内 | 输出到 `/tmp/`（提示无害，校验字节数即可） |
| 上传后 `unexpected end of file` | 上传被截断 | 分卷上传 + 校验 md5 |
| 首轮即 `high`、全程 `high` | 用了有历史数据的 `u_demo` | 换干净账号 `u_sim` |
